# Exercícios

**Exercício 1:** Faça um programa que crie uma matriz de números inteiros na quantidade de linhas e colunas que o usuário informar. Essa matriz deve ser populada automaticamente e ser exibida do primeiro ao último e do último para o primeiro.

**Exercício 2:** Faça um programa que gere uma matriz 3x5 populada automaticamente e baseado nela, gere uma nova matriz inversa (5x3).

**Exercício 3:** Faça um programa que crie e preencha uma matriz quadrada de números inteiros com tamanho que será informada pelo usuário. Mostre os cálculos somando os valores de cada linha, de cada coluna, da diagonal principal e diagonal secundária.

**Exercício 4:** Faça um programa que gere o boletim escolar de um aluno. Critérios: as linhas são as matérias, as colunas são as notas de cada bimestre mais a média e a situação do aluno em cada matéria. Aprovado se a média for maior ou igual a 7; Recuperação se a média for entre 5.1 e 6.9; Reprovado se a média for menor ou igual a 5.
