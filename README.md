# Exercícios

**Exercício 1:** Faça um programa que crie uma matriz de números inteiros na quantidade de linhas e colunas que o usuário informar. Essa matriz deve ser populada automaticamente e ser exibida do primeiro ao último e do último para o primeiro.

**Exercício 2:** Faça um programa que gere uma matriz 3x5 populada automaticamente e baseado nela, gere uma nova matriz inversa (5x3).
